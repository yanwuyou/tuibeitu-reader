# 推背图浏览器 — 设计文档

## 概述

单文件 HTML 网页，将《推背图》六十象以卡片式浏览器形式展示，配朝代时间线导航，原文与白话解读并排呈现。

## 技术选型

纯 HTML/CSS/JS，单文件，零依赖。部署到任意静态托管即可。

## 功能需求

### 核心展示
- 每页展示一象，包含：象序、标题、谶曰、颂曰、金圣叹注解、白话解读
- 原文区三个 tab 切换（谶曰 / 颂曰 / 金批）
- 白话解读区固定展示

### 导航
- 顶部朝代时间线：唐→五代→宋→元→明→清→近现代→未来，标注每段覆盖的象序范围
- 点击时间线节点跳转到该朝代第一象
- 左右箭头翻页（支持键盘 ← →）
- 当前象序指示器（第 X / 60 象）
- URL hash 路由（#3 直接定位第三象，可分享链接）

### 数据内容
- 六十象原文（从知识库 markdown 文件提取）
- 每象白话解读（LLM 生成，逐句拆解关键字词、对应历史事件/人物/时间）

```
├─────────────────────────────────────────┤  ← 标题栏
│  唐 · 五代 · 宋 · 元 · 明 · 清 · 近现代 · 未来 │  ← 时间线导航条

│  谶曰 | 颂曰 | 金批  │                    │
│                    │   白话解读           │

│                    │                    │

│         ← 上一象    第 3 / 60 象    下一象 → │  ← 翻页

```

## 样式基调

- 背景：深灰褐仿古卷质感
- 卡片：宣纸米白（#f5f0e8），圆角，轻微阴影
- 字体：标题衬线体，正文系统默认
- 配色克制，无动画
