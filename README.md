# 《推背图》研读工具

> 一本奇书最适合的阅读方式，不是一个 PDF，而是一个可以被搜索、被筛选、被慢慢翻阅的网页工具。

一个不懂编程的人，用 AI 把《推背图》六十象做成了一个研读工作台 —— 集成原文、金圣叹批注、白话解读、生僻字注音与目录检索。单 HTML 文件，双击打开，无需联网。

**焱无忧的AI手作 出品**

## 使用方式

1. 解压下载包
2. 双击 `tuibeitu.html`，建议用 Chrome 或 Edge 打开
3. 使用左侧目录、搜索框和朝代筛选查找内容
4. 点击“继续阅读”“随机一象”或底部按钮切换内容
5. 通过 URL hash 可直达指定象（如 `tuibeitu.html#39`）

## 技术说明

- 纯 HTML/CSS/JS，零外部依赖
- 数据内联，无需服务器即可运行

## 数据来源

据金圣叹批注版《推背图》整理，白话解读由 AI 辅助生成，仅供参考。
